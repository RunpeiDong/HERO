Controls & tips

  1. Add objects. Choose a table and height. Click an object icon to add it, or to select it if it is already on the table.
  2. Arrange the tabletop. Drag objects within the shaded placement area in the Top View. Start near the robot and keep the approach path and tray clear.
  3. Select a target. Choose an object from Object to pick. The robot uses a horizontal side approach and selects the left or right hand from the object's position.
  4. Run the attempt. Click Pick & place to start the grasp and tray placement. The robot retracts its hands after placement.
  5. Reset or edit. Reset restores the robot and your saved object layout. Remove deletes the selected object; Clear removes all objects.
  6. Inspect the motion. Drag the 3D view to orbit; scroll to zoom. The top-right inset shows the live view from the onboard D435i camera.

Browser IK: Inverse kinematics runs directly on your CPU in the browser, without cuRobo. Solve times, IK solutions, and resulting robot motion may differ from cuRobo running on CUDA.

Keep the tray clear: Objects already resting in the tray can leave no collision-free release path for the next placement, so the arm may jitter or hesitate above the tray while it searches for one. Remove or Clear placed objects before picking the next one.
